# Folding selected subtrees

Pins cli/build/README.MD "Folding subtrees": a true flag absorbs its whole
branch into the nearest surviving ancestor. A false descendant cannot reopen
it. Siblings remain distributed, and a pruned intermediate directory does not
become a destination. Constraint-only folding preserves selection scopes;
dynamic nodes remain shared. Maps, exclusion reasons and local machinery move
with the folded content. A child Espalier remains independent.

The marked shared document is deleted. The unmarked features document remains
untouched: it is no longer an output path and cannot be swept as an orphan.
